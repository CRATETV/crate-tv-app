# Roku Channel Store artwork

Upload these on developer.roku.com → your channel → **Store info** (or wherever the form asks for artwork).
They are NOT part of the channel itself and are not sent to TVs.

| File | Use |
|---|---|
| `roku-store-channel-poster-540x405.png` / `.jpg` | Channel poster (required) |
| `roku-store-channel-poster-hd-290x218.png` | HD poster, if asked |
| `roku-store-channel-poster-sd-246x140.png` | SD poster, if asked |
| `roku-store-splash-1920x1080.png` | Large artwork, if asked |

Screenshots (up to 6, 1920×1080) must be real screens: on your dev Roku's page `http://<IP>` → Utilities → Screenshot.
